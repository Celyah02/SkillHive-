🌐 SkillHive

SkillHive is a modern and user-friendly online learning platform built to help users explore courses, watch educational videos, and manage their learning profiles. Designed with clean UI and smooth navigation to offer a great learning experience.

🔗 Live Demo: https://skill-hive-lac.vercel.app/

✨ Features

🏠 Homepage with featured learning categories

📚 Browse and view available courses

▶️ Watch course videos in a dedicated player page

👤 User profile page

📝 Teacher profile sections

🔐 Login & Registration pages

📱 Fully responsive UI design
